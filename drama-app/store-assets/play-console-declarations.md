# คำตอบสำหรับ Play Console: Data safety และ Content rating

อ้างอิงจากโค้ดและ build ปัจจุบัน (versionCode 2): สิทธิ์เดียวคือ `INTERNET`, ไม่มี SDK โฆษณา/analytics/Firebase (ไม่มี `google-services.json`), ไม่มีบัญชีผู้ใช้, `fetch` เดียวคืออ่าน `library.json` ในแอปเอง
Play Console อาจปรับหน้าตาแบบฟอร์ม ให้ตอบตามความหมายของแต่ละข้อ

## 1. Data safety

| คำถาม | คำตอบ |
|---|---|
| แอปเก็บหรือแชร์ข้อมูลผู้ใช้ประเภทที่ต้องประกาศหรือไม่ | **ไม่ (No)** |
| ข้อมูลทุกประเภท (ตำแหน่ง, ข้อมูลส่วนบุคคล, การเงิน, สุขภาพ, ข้อความ, รูป/วิดีโอ, ไฟล์, ปฏิทิน, รายชื่อติดต่อ, กิจกรรมแอป, ประวัติเว็บ, ข้อมูลอุปกรณ์/ID อื่น) | ไม่เก็บ ไม่แชร์ |
| ข้อมูลถูกเข้ารหัสระหว่างส่งหรือไม่ | ข้ามได้ (ไม่มีข้อมูลที่ส่ง) |
| ผู้ใช้ขอลบข้อมูลได้หรือไม่ | ไม่มีบัญชี จึงไม่มีข้อมูลฝั่งเรา ผู้ใช้ลบข้อมูลในเครื่องเองได้ด้วยการล้างข้อมูลแอปหรือถอนการติดตั้ง |
| ลิงก์นโยบายความเป็นส่วนตัว | https://envburiram.github.io/drama/privacy.html |

เหตุผลที่ตอบว่า "ไม่เก็บ":
- รายการซีรีส์ ลิงก์ และความคืบหน้าอยู่ใน localStorage บนเครื่อง ไม่ถูกส่งออก (Play ถือว่าข้อมูลที่ประมวลผลบนเครื่องเท่านั้นไม่ใช่ "การเก็บ")
- แอปไม่มีเซิร์ฟเวอร์ของผู้พัฒนา

ข้อควรระวัง (โปรดอ่านก่อนกดส่ง):
- เมื่อเล่นวิดีโอ อุปกรณ์เชื่อมต่อกับเซิร์ฟเวอร์ของลิงก์ที่ผู้ใช้เลือกเอง ซึ่งเห็น IP ตามปกติของการเชื่อมต่อ ผมตีความว่าเป็นการที่ผู้ใช้สั่งเองและไม่ผ่านผู้พัฒนา จึงไม่ต้องประกาศ แต่ **เป็นการตีความของผม ไม่ใช่คำยืนยันจาก Google** หากต้องการความแน่นอน ให้ตรวจกับคำนิยามในหน้า Data safety ของ Play Console หรือฝ่ายกฎหมาย
- เมื่อเพิ่ม SDK ใหม่ (analytics, โฆษณา, crash report) ต้องกลับมาแก้ฟอร์มนี้และนโยบายความเป็นส่วนตัว
- `allowBackup=true` ในแมนิเฟสต์ ทำให้ระบบสำรองข้อมูลของ Android อาจสำรองข้อมูลแอปไปยังบัญชี Google ของผู้ใช้เอง ไม่ผ่านผู้พัฒนา ไม่ต้องประกาศ

## 2. Content rating (แบบสอบถาม IARC)

หมวดแอปที่ควรเลือก: **Utility, Productivity, Communication, or Other** (หรือหมวดเครื่องเล่นสื่อ/"All other app types" ตามที่ฟอร์มมีให้)

| หัวข้อ | คำตอบ |
|---|---|
| ความรุนแรง (Violence) | ไม่ |
| เนื้อหาทางเพศ/เปลือย | ไม่ |
| ภาษาหยาบคาย | ไม่ |
| สารเสพติด/แอลกอฮอล์/ยาสูบ | ไม่ |
| การพนัน (จำลองหรือจริง) | ไม่ |
| เนื้อหาน่ากลัว | ไม่ |
| ผู้ใช้สร้างเนื้อหาและแชร์ให้ผู้ใช้อื่น (UGC) | ไม่ (ลิงก์ที่ใส่เก็บในเครื่องตัวเอง ไม่แชร์) |
| ผู้ใช้โต้ตอบหรือสื่อสารกัน | ไม่ |
| แชร์ตำแหน่งที่ตั้ง | ไม่ |
| ซื้อของดิจิทัลหรือจ่ายเงินในแอป | ไม่ |
| การเข้าถึงอินเทอร์เน็ต/เนื้อหาภายนอก | ตอบตามจริง: แอปเล่นวิดีโอจากลิงก์ที่ผู้ใช้ใส่เอง แอปไม่ได้จัดหรือคัดกรองเนื้อหานั้น |

ข้อควรระวัง:
- แอปเองไม่มีเนื้อหาที่ต้องจัดเรทสูง แต่เพราะเล่นลิงก์ใดก็ได้ ผลเรทติ้งที่ได้ (เช่น Everyone/PEGI 3 หรือสูงกว่า) **ผมไม่สามารถยืนยันล่วงหน้าได้** ต้องรอผลจากแบบสอบถามจริง และตอบตามความจริงเสมอ การตอบไม่ตรงอาจทำให้แอปถูกระงับ
- ถ้าใส่ภาพหน้าจอหรือคำอธิบายที่มีคอนเทนต์ผู้ใหญ่ ต้องตอบให้สอดคล้อง (ภาพที่ทำไว้ใช้วิดีโอตัวอย่างพื้นไล่สี ไม่มีเนื้อหาดังกล่าว)

## 3. ข้อมูลอื่นที่ Play Console จะถาม (คำตอบที่สอดคล้องกัน)

| หัวข้อ | คำตอบ |
|---|---|
| Target audience (กลุ่มอายุเป้าหมาย) | **18 ปีขึ้นไป หรือ 13 ปีขึ้นไป** ไม่เลือกกลุ่มเด็ก (ไม่ใช่แอปสำหรับเด็ก จึงไม่เข้าข่ายนโยบาย Families) |
| มีโฆษณาหรือไม่ | ไม่มี |
| App access (ต้องล็อกอินหรือไม่) | ใช้ได้ทุกฟีเจอร์โดยไม่ต้องล็อกอิน ไม่ต้องให้บัญชีทดสอบ |
| แอปการเงิน / สุขภาพ / ข่าว / ภาครัฐ | ไม่ใช่ทั้งหมด |
| บริการ VPN / Accessibility / SMS / ตำแหน่งเบื้องหลัง | ไม่ใช้ |
| Advertising ID | ไม่ใช้ (ไม่ต้องประกาศ ไม่มีสิทธิ์ `AD_ID` ในแอป ตรวจจากแมนิเฟสต์แล้ว มีสิทธิ์เดียวคืออินเทอร์เน็ต) |
| หมวดหมู่แอป | Video Players & Editors |
